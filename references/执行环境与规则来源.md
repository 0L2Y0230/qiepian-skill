# 独立分享版执行环境

本技能面向提供文件读取能力的 Agent 环境，包括 Codex、DeepSeek Harness、豆包工作和 Kimi Code。默认使用本技能目录中 references 下的完整规则，不依赖作者电脑、固定盘符、私有云盘或聊天记忆。跨宿主安装方式见技能根目录 docs/安装与兼容性.md；兼容格式与实际行为测试分别记录，不能把文档适配宣称为三家产品均已实测。

## 规则来源

本包四份业务规则来自用户提供的 V5.1 独立规则包，来源快照日期为 2026-10-31，保留原文件字节。主文件是唯一业务真相源；短卡、验收方法和本技能摘要不反向覆盖主文件。

每次生成或修改正式方案，都重新读取总控、执行卡与完整主规则，交付前读取验收卡。更严格的适用用户或项目读取要求继续生效。业务规则中的 GLOBAL-EXEC、云盘文件 ID、项目附件、历史档案等是来源环境引用：本地执行映射到所选规则根目录的同名四文件；不得伪称访问原作者云盘，也不需要查找未随包提供的历史文件。

默认读取顺序：本文件 → 独立版总控执行卡.md → 切片文案执行卡.md → 完整切片文案.md → 执行 → 独立版强制验收卡.md → 交付。输出截断时补齐全文。

## 本机覆盖

可在技能根目录建立不提交的 config.local.json，格式见 config.example.json。rules_root 指向一个包含全部四份规则的目录，environment_file 指向额外环境入口。相对路径以技能目录为基准；相对 output_dir 以使用者工作目录为基准。选用外部规则时仍先读取本文件，再读取指定入口和该来源全部规则；缺失时不得从随包文件拼补。版本报告以实际读取来源为准。

这个配置只改变来源与保存位置，不授权修改规则、移动原始素材、覆盖交付或访问其他项目。不存在配置时直接使用包内规则，无须创建配置。

## 素材、产物与核验

原始素材留在用户指定位置；默认产物保存到使用者工作目录下的 outputs，不能写入技能安装目录。只有 SRT 也正常交付，但具体画面、原声和精确剪点保持待核实。视频可读取时定向检查最终候选与歧义点，不默认全视频通览。

本包 tests/fixtures 内仅有虚构 SRT 测试素材，没有真实视频，不能作为实际营销口播事实发布。Python 脚本仅供打包与文件完整性校验，生成文案不依赖 Python；技能不会自动下载模型、安装依赖或发布视频。
